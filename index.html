홈 화면에 바로가기 추가 방법

스마트폰 홈 화면에 추가해 두시면 앱처럼 터치 한 번으로 스위트잉크 관리 안내를 다시 확인하실 수 있습니다.

iOS 아이폰 (Safari 브라우저)
  1. 화면 하단의 공유 버튼 (□↑)을 눌러주세요.
  2. 메뉴를 아래로 내려 ‘홈 화면에 추가’를 선택하세요.
  3. 우측 상단의 ‘추가’를 누르면 완료됩니다.
Android 안드로이드 (Chrome 브라우저)
  1. 우측 상단의 더보기 버튼 (⋮)을 눌러주세요.
  2. 메뉴에서 ‘홈 화면에 추가’를 선택하세요.
  3. ‘추가’를 누르면 홈 화면에 아이콘이 생성됩니다.
